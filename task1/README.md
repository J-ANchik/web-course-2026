# task1 — Семантическая вёрстка. Страница-резюме

Одностраничное резюме на семантическом HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`), раскладка блоков — только на Flexbox (`justify-content`, `align-items`, `flex-direction`, `flex-wrap`, `gap`). JavaScript не используется; переключатель светлой/тёмной темы в шапке сделан на чистом CSS (чекбокс + `:has()`).

**Как запустить:** открыть `index.html` в браузере, либо перейти по ссылке GitHub Pages: `https://j-anchik.github.io/web-course-2026/task1/`.
