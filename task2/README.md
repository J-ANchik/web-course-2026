# task2 — Адаптивная вёрстка. Лендинг по макету

Одностраничный лендинг IT-конференции «CodeWave 2026» с адаптацией под три контрольные точки (мобильный / планшет / десктоп), подход Mobile First. Крупная сетка страницы (шапка, герой-секция, карточки, футер) — на CSS Grid (`display: grid`, `grid-template-columns`, `grid-template-rows`, `gap`), раскладка внутри компонентов (навигация, кнопки, содержимое карточек, форма) — на Flexbox. JavaScript не используется; гамбургер-меню и переключатель светлой/тёмной темы сделаны на чистом CSS (чекбокс + `:checked`).

**Как запустить:** открыть `index.html` в браузере, либо перейти по ссылке GitHub Pages: [https://j-anchik.github.io/web-course-2026/task2/](https://j-anchik.github.io/web-course-2026/task2/).
