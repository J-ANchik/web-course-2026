# task3 — Основы JS и DOM: Todo-list

Интерактивный список задач в виде доски с «приклеенными» заметками, без сохранения данных между перезагрузками страницы. 
Добавление задачи — через поле ввода и кнопку «Приклеить» или клавишу Enter; пустое поле не добавляется в список и показывает предупреждение. 
У каждой задачи — кнопка отметки выполненной (класс `.completed` с зачёркиванием текста и уменьшением непрозрачности) и кнопка удаления. 
Список задач хранится в JS как массив объектов `{ id, text, completed }`, 
вся разметка отдельных задач генерируется через `document.createElement` и перерисовывается функцией `render()` при любом изменении данных, 
с использованием `map`/`filter`/`forEach`. Фильтр из трёх вкладок («Все» / «Активные» / «Завершённые») скрывает неподходящие задачи, 
не удаляя их из массива. Счётчик над списком показывает количество оставшихся и выполненных задач. Все события обрабатываются через `addEventListener`, 
без `onclick` в разметке.

**Как запустить:** открыть `index.html` в браузере, либо перейти по ссылке GitHub Pages: [https://j-anchik.github.io/web-course-2026/task3/](https://j-anchik.github.io/web-course-2026/task3/).
