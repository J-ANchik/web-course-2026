# task4 — Игра «Быки и коровы»

Браузерная игра «Быки и коровы» на чистом JavaScript и DOM (без Canvas и сторонних библиотек).  
Компьютер загадывает число из 4 неповторяющихся цифр, игрок вводит попытки, а после каждой видит количество «быков» (цифра на своём месте) и «коров» (цифра есть, но стоит на другом месте). Состояние игры (загаданное число, массив истории попыток вида `{ guess, bulls, cows }`, флаг окончания игры) хранится в JS, а интерфейс перерисовывается функцией `render()` на основе этих данных. Логика разбита на отдельные функции: `generateSecret()` — генерация числа, `validateGuess()` — валидация ввода (ровно 4 цифры, только цифры, все разные), `countBullsAndCows()` — подсчёт быков и коров. Реализованы история попыток в виде «1234 → 1 бык, 2 коровы», счётчик попыток, сообщение о победе с блокировкой ввода и кнопка «Новая игра», которая сбрасывает игру без перезагрузки страницы. Обработка событий — через `addEventListener`, стили вынесены в `style.css`.
