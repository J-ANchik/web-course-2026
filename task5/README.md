# task5 — Игра Simon («Симон говорит»)

Браузерная игра Simon: компьютер показывает последовательность подсвечивающихся цветных секторов, игрок повторяет её в том же порядке. После каждого верного раунда последовательность удлиняется на один случайный элемент и показывается заново с начала; при ошибке игра завершается и выводится достигнутый уровень. Четыре сектора собраны в круг на CSS Grid (сетка 2×2), раскладка остальных элементов (кнопки управления, центр с номером уровня) — на Flexbox. Показ последовательности реализован через `async/await` с `Promise` и `setTimeout`; `setInterval` не используется, а все таймеры регистрируются в одном реестре и отменяются при ошибке или перезапуске, поэтому старые и новые последовательности не накладываются. Состояние игры (последовательность, ввод игрока, фаза «показ / ввод») хранится в объекте, а не в CSS-классах. Дополнительно: звук через `AudioContext` (можно отключить чекбоксом) и управление клавишами 1–4.

**Как запустить:** открыть `index.html` в браузере, либо перейти по ссылке GitHub Pages: [https://j-anchik.github.io/web-course-2026/task5/](https://j-anchik.github.io/web-course-2026/task5/).
