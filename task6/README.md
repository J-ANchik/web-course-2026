# task6 — Игра на Canvas («Змейка»)

Классическая «Змейка» на `<canvas>` (поле 20×20 клеток по 20px) с управлением стрелками клавиатуры. 
Код в `script.js` разбит на слои по шаблону MVC: Model (состояние змейки, яблока и счёта, правила движения и столкновений), 
View (отрисовка на Canvas и обновление HTML-элементов), Controller (обработка клавиатуры и игровой цикл); весь код обёрнут в IIFE, глобальных переменных нет. 
Игровой цикл построен на `requestAnimationFrame` с расчётом по прошедшему времени (`deltaTime`, шаг каждые 150 мс), `setInterval` не используется; 
разворот на 180° игнорируется. После столкновения со стеной или хвостом выводится «Игра окончена» с итоговым счётом и кнопка «Начать заново» (или клавиша Enter).
Раскладка страницы — на Flexbox.

**Как запустить:** открыть `index.html` в браузере, либо перейти по ссылке GitHub Pages: [https://j-anchik.github.io/web-course-2026/task6/](https://j-anchik.github.io/web-course-2026/task6/).
