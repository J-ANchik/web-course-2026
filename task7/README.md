# Лабораторная №7. Лента постов с бесконечным скроллом

Лента постов из jsonplaceholder: подгрузка по 10 штук при прокрутке, поиск по заголовку с дебаунсом 300 мс, индикатор загрузки и обработка ошибок сети. Код на чистом JS, разбит на слои MVC (`PostsApi` → `Model` → `View` → `Controller`), глобальных переменных нет (всё внутри IIFE).

Запуск: открыть `index.html` в браузере или [https://j-anchik.github.io/web-course-2026/task7/](https://j-anchik.github.io/web-course-2026/task7/).
